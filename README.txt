OSTROV MALDIVES FINANCE MANAGER — ROOM CAPACITY UPDATE

This is the same Finance Manager app with Excursions, Restaurant POS, Income, Expenses, Transactions, Reports and Settings.

Update included:
- Total rooms defaults to 20.
- Room count can be changed to any whole number 1 or higher in Reports & Settings.

To publish on GitHub Pages, upload index.html (not the ZIP) to the root of your repository, then enable Settings > Pages > Deploy from a branch > main > /(root).

Important: this prototype stores records in the browser on the device and does not sync between devices. Export backups regularly. It is not yet a secure shared business database.
